# AI CyberSuit - AI Powered Cybersecurity Platform

AI CyberSuit is a modern AI-based cybersecurity platform developed to detect, analyze, and monitor multiple cyber threats using Machine Learning and intelligent security analysis.

The project combines 8 different cybersecurity tools into a single platform with a modern React-based frontend and Python backend.

---

# Features

## Integrated Security Tools

### 1. Phishing Scanner
Detects phishing URLs and suspicious websites using machine learning techniques.

### 2. Malware Analysis
Analyzes suspicious files and identifies malicious behavior patterns.

### 3. Network IDS (Intrusion Detection System)
Monitors network traffic and detects unauthorized or suspicious activities.

### 4. Behavioral Analytics
Identifies abnormal user or system behavior using behavioral analysis techniques.

### 5. Email Security Scanner
Scans emails for spam, phishing attempts, malicious attachments, and suspicious content.

### 6. Fraud Detection
Detects unusual or fraudulent activities using predefined datasets and AI models.

### 7. Deepfake Scanner
Analyzes media content to detect AI-generated or manipulated deepfake content.

### 8. 0-Day Code Scanner
Scans source code and scripts to identify suspicious or potentially dangerous vulnerabilities.

# System Workflow

1. User uploads files, URLs, emails, or code
2. Backend processes the input
3. AI/ML models analyze suspicious patterns
4. Security engine generates threat analysis
5. Results are displayed through the React dashboard
